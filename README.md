# VersionControlAssignment

1.	Version Control is a way of saving changes for a project while maintaining 
	old versions that can be reverted to at any point in timewith a time stamp.
	It is used to allow multiple programmers to work on a project at once
	while not interrupting anyone's workflow as well as allowing you to go back
	to older version in case of catastrophic failure. It also lets programmers
	see the changes to their code as it is being developed.

2.	Git is a software created by Linus Torvalds to communicate files to servers
	while maintaining version control and documenting changes. Github is a
	website owned by Microsoft to host files, versions, and connect with Git.

3.	"git Status" checks what changes you made to a Git directory on your computer
	that have not been added to the main repo. "git add" prepares the file to
	be sent to your repository. "git commit -m ''" allows you to document what
	you changed. "git push" actually pushes the change to the repository.
